# Дом Фарфора — ABC-фид

Этот отдельный фид не изменяет исходный фид клиента. Каждые четыре часа GitHub Actions:

1. скачивает актуальный товарный XML;
2. исключает товары брендов из `blocked_vendors.txt`;
3. загружает опубликованную CSV-таблицу со статистикой;
4. сопоставляет товары по точному нормализованному названию;
5. добавляет каждому товару `custom_label_0`;
6. проверяет XML и публикует готовый файл в постоянном GitHub Release.

Значения метки:

- `1` — больше двух конверсий;
- `2` — одна или две конверсии;
- `3` — ноль конверсий или товар не найден в статистике.

Если одно название встречается в CSV несколько раз, конверсии суммируются. Регистр, лишние пробелы, HTML-сущности и совместимые варианты Unicode при сопоставлении не учитываются. Нечёткое сопоставление намеренно не используется: оно могло бы приписать конверсии другому товару.

Постоянная ссылка на собранный файл:

`https://github.com/Loungechill/DomFarforaABC/releases/download/feed-latest/feed.xml`

`worker.js` — готовый модульный скрипт для Cloudflare Workers. После публикации Worker отдаёт фид по `/feed.xml` и `/`.
